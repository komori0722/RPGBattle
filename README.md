# コマンド式 RPG バトルゲーム (Java)

Javaの基本文法（Scanner, while, if-else, Math.random）を活用して開発した、コンソール上で動作するコマンド選択型RPGバトルゲームです。

---

## ゲーム概要

プレイヤーは勇者となり、立ちはだかる魔王と1対1のターン制バトルを行います。  
状況に応じて「攻撃」「回復」「逃げる」のコマンドを正しく選択し、勝利を目指します。

---

## 主な機能と特徴

- **ダイナミックなダメージ倍率システム**
    - 通常攻撃の際、`Math.random()` を用いて **0.5倍 〜 1.5倍（0.1刻み）** のダメージ変動ロジックを実装。毎回異なるダメージ展開が楽しめます。
- **リソース管理（MP & HP）**
    - 回復コマンド（MP 5消費）を使用することで、HPを **8 〜 30** の範囲でランダム回復可能。MPが切れた場合は回復できず、ターンが無駄にならないよう再入力処理（`continue`）を配置。
- **ターン制反撃ロジック**
    - プレイヤーの行動後、ボスのHPが残っている場合のみボスが反撃を行います。
- **入力チェックと制御構造**
    - 無効なコマンドが入力された場合はメッセージを表示し、`continue` により敵のターンを進めずにコマンド選択へ復帰します。

## 開発環境・使用技術

- **言語**: Java (JDK 21)
- **開発環境 (IDE)**: IntelliJ IDEA
- **主要クラス・標準ライブラリ**:
    - `java.util.Scanner` （ユーザー入力の取得）
    - `java.lang.Math` （ランダム値・倍率計算）
